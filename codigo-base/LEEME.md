# Código base · Gimnasio Admin (Prácticas 19 a 23)

El panel de administración del gimnasio, en Angular. Un solo zip para toda la unidad; cada carpeta
dice en qué práctica se usa. Nada de esto se teclea: se copia y se recorre.

| Carpeta | Práctica | Se copia a |
|---|---|---|
| `practica-19/styles.css` | 19 | `src/styles.css` (reemplaza el que trae) |
| `practica-19/public/` | 19 | `public/` (el logo y las 8 imágenes) |
| `practica-19/modelos/` y `datos/` | 19 | `src/app/` |
| `practica-21/` (todo) | 21 | `src/app/` — la sesión, los interceptores, el guardia, el login y el marco del panel |

Las Prácticas 20, 22 y 23 no tienen código base.

La API es `gimnasio-backend` con los cambios de la Unidad IV (CORS para el 4200, crear, editar y
borrar sólo con rol admin). Cuenta del administrador: `admin@itson.mx` / `gimnasio2026`.
